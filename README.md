## 🏗️ Technical Architecture & Stack

Strictly engineered with zero third-party framework dependencies for instant load performance, maximum control, and visual distinction:

- **Markup**: Semantic HTML5 with accessibility attributes (`aria-*`, `role`), structured metadata, and OpenGraph tags.
- **Styling**: Vanilla CSS3 with Dual-Theme System (`:root` / `[data-theme="dark"]` vs `[data-theme="light"]`), CSS Grid, Flexbox, and Glassmorphism.
- **Client Logic**: Pure Vanilla ES6+ JavaScript (`app.js`) powering the 360° sequence canvas renderer, navigation scroll-spy, investigation workbench, clipboard utilities, and theme persistence.
- **No Dependencies**: 0% React, 0% Next.js, 0% Tailwind, 0% Bootstrap. Fast, lightweight, and recruiter-ready.

## 🚀 Running Locally

Because this project is built with Vanilla web standards, no build step or node installation is required:

### Option 1: Python Built-in Server (Recommended)
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

### Option 2: Direct Browser Open
Simply double-click or open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).
